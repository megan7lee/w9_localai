單元二：網頁爬蟲基礎

學習用 Python 下載網頁、解析 HTML，擷取你想要的資料。

1. 用 requests 下載網頁

requests 是 Python 最常用的 HTTP 套件，可下載網頁原始碼。

pythonimport requests

url = 'https://example.com'
resp = requests.get(url, headers={'User-Agent': 'Mozilla/5.0'})
print('狀態碼：', resp.status_code)
print('網頁長度（字元）：', len(resp.text))
print(resp.text[:300])

爬蟲禮儀（務必遵守）：查看網站的 /robots.txt；不要短時間大量請求（可加入 time.sleep(1)）；只擷取公開資料，尊重著作權與隱私。

2. 用 BeautifulSoup 解析 HTML

為了離線練習，我們先把一個「範例網頁」儲存為本地檔案 sample.html，再從檔案讀取練習（不需要網路）。

pythonhtml_content = '''<!DOCTYPE html>
<html lang="zh-TW">
<head><meta charset="UTF-8"><title>範例書店</head>
<body>
  <h1 class="site-title">📚 範例線上書店</h1>
  <table class="books">
    <tr><th>書名</th><th>作者</th><th>價格</th></tr>
    <tr><td>Python 入門</td><td>小明</td><td class="price">380</td></tr>
    <tr><td>資料視覺化實戰</td><td>小華</td><td class="price">520</td></tr>
    <tr><td>爬蟲從零開始</td><td>小美</td><td class="price">450</td></tr>
  </table>
  <a href="/about">關於我們</a>
  <a href="/contact">聯絡</a>
</body>
</html>'''
with open('sample.html', 'w', encoding='utf-8') as f:
    f.write(html_content)
print('sample.html 已建立')
pythonfrom bs4 import BeautifulSoup

with open('sample.html', encoding='utf-8') as f:
    soup = BeautifulSoup(f, 'html.parser')

# 取標題
title = soup.find('h1', class_='site-title').get_text(strip=True)
print('網站標題：', title)

# 取所有連結
for a in soup.find_all('a'):
    print('連結：', a.get_text(strip=True), '->', a.get('href'))

# 取價格欄位
prices = [td.get_text(strip=True) for td in soup.select('td.price')]
print('價格清單：', prices)
預期輸出網站標題： 📚 範例線上書店
連結： 關於我們 -> /about
連結： 聯絡 -> /contact
價格清單： ['380', '520', '450']

常用 BeautifulSoup 方法

  • soup.find(tag, class_=...) — 找第一個符合的元素
  • soup.find_all(...) — 找全部符合的元素
  • soup.select('CSS 選擇器') — 如 select('td.price')
  • .get_text(strip=True) — 取出純文字
  • .get('href') — 取出屬性值

單元六：完整實作專案

把爬蟲、清理、視覺化串接成一支可執行的 Python 腳本。

完整腳本：project.py

pythonimport requests
from bs4 import BeautifulSoup
import pandas as pd
import matplotlib.pyplot as plt

# 1. 擷取（此處以本地 sample.html 練習；實際上線可改用 requests.get(url)）
with open('sample.html', encoding='utf-8') as f:
    soup = BeautifulSoup(f, 'html.parser')

rows = []
for tr in soup.select('table.books tr')[1:]:
    cols = tr.find_all('td')
    if len(cols) == 3:
        rows.append({
            '書名': cols[0].get_text(strip=True),
            '作者': cols[1].get_text(strip=True),
            '價格': cols[2].get_text(strip=True),
        })

df = pd.DataFrame(rows)

# 2. 清理
df = df.drop_duplicates()
df['作者'] = df['作者'].fillna('未知')
df['價格'] = pd.to_numeric(df['價格'], errors='coerce').fillna(0).astype(int)
df.to_csv('books_clean.csv', index=False, encoding='utf-8-sig')

# 3. 視覺化
plt.rcParams['font.family'] = 'Microsoft JhengHei'
plt.figure(figsize=(7,4))
plt.bar(df['書名'], df['價格'], color='#2e86ab')
plt.title('各書籍價格')
plt.ylabel('價格（元）')
plt.xticks(rotation=15)
plt.tight_layout()
plt.savefig('price_bar.png', dpi=150)
plt.show()

print('=== 最終清理後資料 ===')
print(df)
print('圖表已儲存：price_bar.png')
